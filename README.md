# Angel Buddy

An AI-powered assistant that guides beginner entrepreneurs through the key areas of running a business.

## Problem We Solve
Beginner entrepreneurs often feel overwhelmed managing their business alone. They lack access to affordable mentorship, get lost in too much generic information, and struggle to stay motivated and consistent — especially when it comes to managing people, which business advisors identify as one of the biggest challenges for small businesses.

## Solution
Angel Buddy is a warm, guided AI assistant that helps entrepreneurs navigate five key business areas: **Marketing, Finance, Sales, Operations, and People/HR**. Instead of overwhelming users with information, it asks guiding questions and gives concrete, actionable advice — like a real mentor would. It also includes a **Resources & News** feed with curated articles for each business area.

The app is built for a Spanish-speaking audience, so the interface is in Spanish.

## AI / Technical Approach
Angel Buddy was built using **IBM Bob** as the primary AI development tool. Bob generated the full frontend (HTML, CSS, JavaScript), including the guided chat logic, the business area content, and the resources feed. Bob was also used to iteratively debug and improve the application throughout development.

## How We Used IBM Bob
- Generated the initial HTML/CSS/JS structure of the application from a natural language description
- Diagnosed and fixed a modal click-event bug during testing
- Expanded and refined the chat responses for each business area with more guided, mentor-style questions
- Fixed non-functional resource links in the "Resources & News" section

## Technologies Used

## Main Features
